## Recent Projects

### Personal Expense Tracker
Full-stack application for tracking and analyzing personal finances.

Built the complete stack: FastAPI backend with PostgreSQL database, React + TypeScript frontend with TailwindCSS, deployed on Vercel. Implemented user authentication, expense categorization, analytics, and a responsive interface.

**What I learned:** Full-stack means everything matters—API performance, database indexing, authentication security, and frontend user experience all affect whether people actually use the application.

### Voice AI Study Coach
AI-powered learning assistant that provides personalized study support through conversation.

Built the system architecture to coordinate multiple AI agents—handling user input, retrieving study materials, generating explanations, and maintaining conversation state. Worked with LLMs and prompt engineering to make the AI actually useful for learning.

**What I learned:** AI systems need the same engineering rigor as any other system. State management, error handling, and testing matter just as much as the model quality.
